# Retention Copilot

An AI assistant (Hoppy) that helps HEINEKEN sales reps spot at-risk accounts, plan visits 3 days ahead and bring an approved offer to every visit.

## What it does
1. **Identify:** a risk score built on each account's order rhythm, validated on months the model never saw.
2. **Prioritise:** P1–P2 get a rep visit; Hoppy handles P3–P5 remotely (win-back call, care note, monitor).
3. **Act:** a 3-day plan with offers by approval level, expected profit per offer, route, drive mode with audio briefing, and one-tap outcome logging.

*Student prototype for the HEINEKEN × AISO challenge. Uses the anonymised challenge dataset; not an official HEINEKEN product.*
